# Проверка LED C5G

Доверенный диагностический пример, отдельно от рабочего шаблона.
Источник пинов: [C5G User Manual v7, таблица 3-4, стр. 31](https://solitonwave.co.jp/shop_pro/download/fpga/terasic/c5g/C5G_User_Manual_v7.pdf).
Кандидат отображения: dout[0..9] → LEDR0..9, dout[10..17] → LEDG0..7.
Высокий уровень включает LED; стандарт выходов 2.5 V.
Физическое соответствие всех 18 выходов пока не подтверждено.

Из `src/fpga`:

```sh
make test-led
(cd quartus && quartus_sh --flow compile led_check)
quartus_pgm -c 1 -m jtag -o 'p;build/led_check/led_check.sof@1'
```

После загрузки повторяется 20-секундный цикл, каждая фаза — секунда:
всё выключено → всё включено → LEDR0, LEDR1, …, LEDR9 → LEDG0, …, LEDG7.
Наблюдатель проверяет маркировку каждого одиночного LED, отсутствие лишних
горящих LED, полное выключение и включение. Записать дату, результат всех
18 позиций и любые отклонения; успешная прошивка не заменяет эту проверку.
