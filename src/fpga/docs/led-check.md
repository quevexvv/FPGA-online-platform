# Проверка светодиодов

Этот тест нужен, чтобы связать биты результата с настоящими светодиодами:
какой бит включает какой LED и какой уровень означает «включено».

Проверенное соответствие:

- `dout[0..9]` — красные LEDR0..LEDR9;
- `dout[10..17]` — зелёные LEDG0..LEDG7;
- логическая 1 включает светодиод, 0 выключает его.

Пины взяты из [руководства C5G, таблица 3-4, стр. 31](https://solitonwave.co.jp/shop_pro/download/fpga/terasic/c5g/C5G_User_Manual_v7.pdf)
и проверены на плате. Для выходов используется стандарт 2.5 V.

Команды из `src/fpga`:

```sh
make test-led
(cd quartus && quartus_sh --flow compile led_check)
quartus_pgm -c 1 -m jtag -o 'p;build/led_check/led_check.sof@1'
```

После загрузки повторяется цикл: всё выключено → всё включено → по одному
LEDR0..LEDR9 → по одному LEDG0..LEDG7. Каждое состояние длится секунду,
полный цикл — 20 секунд. Нужно сверить маркировку всех LED и убедиться,
что при одиночном включении остальные погашены.

Симуляция двух циклов, сборка, загрузка и визуальная сверка пройдены.
Использовались Icarus 13.0 и Quartus Lite 23.1std.0 Build 991.
Запасы по времени setup/hold/ширине импульса: 15.509 / 0.164 / 9.085 нс.
Все проверяемые пути имеют временные ограничения.

При сборке осталось два предупреждения: недоступная без подписки функция
LogicLock и неуказанные сила тока/slew rate выходов LED. Ошибок сборки нет.
