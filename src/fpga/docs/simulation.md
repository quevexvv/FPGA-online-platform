# Проверки без платы

Симулятор запускает HDL на компьютере. Вместо настоящих проводов и LED
тест задаёт сигналы и проверяет ответы схемы. Так можно быстро обнаружить,
например, лишний такт или неправильный результат счётчика.

Для обычного Verilog-2001 проверен Icarus Verilog 13.0:

```sh
make test-simulator
```

Команда запускает два теста. Правильный должен завершиться с кодом 0,
намеренно ошибочный — с кодом 1. Оба случая проверены: ошибки схемы
не остаются незамеченными из-за успешного завершения симулятора.

Все обычные HDL-тесты запускаются через `make test-hdl`. Плата и Quartus
для них не нужны. Эта команда также включена в CI; удалённый запуск CI
в рамках этих проверок не выполнялся.

## Почему не подошёл ALTCLKCTRL

ALTCLKCTRL — готовый блок управления тактовым сигналом от производителя
ПЛИС. Для точной симуляции нужна его модель — описание поведения блока.
В установленном Quartus Lite 23.1 часть модели Cyclone V зашифрована,
и Icarus не смог её использовать.

Проверить совместимость своей установки можно так, указав каталог Quartus:

```sh
make probe-vendor QUARTUS_ROOTDIR=/path/to/quartus
```

Получена ошибка `Unknown module type: cyclonev_clkena_encrypted`, код 2.
Поэтому поведение ALTCLKCTRL пока не подтверждено. Вместо него отдельно
проверен [генератор на регистре](clock-experiment.md).

Для продолжения проверки ALTCLKCTRL нужен совместимый ModelSim/Questa,
библиотека Cyclone V и рабочая лицензия. Их доступность не подтверждена.
