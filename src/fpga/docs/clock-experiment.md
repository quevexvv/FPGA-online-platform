## Отдельный кандидат: зарегистрированный медленный генератор

`clock_burst.v` создаёт выход непосредственно регистром, без комбинационного
gate. 50 МГц / (2 × 25) = 1 МГц. Глобальная маршрутизация и SDC проверяются
отдельно на плате; до этого кандидат не считается аппаратно принятым.
Это ограничивает поддерживаемый clock студенческой схемы до 1 МГц.
16-битное поле steps задаёт формат эксперимента, не эксплуатационный лимит.

Start принимается только при busy=0, во время busy игнорируется.
Все команды последовательны: хост должен дождаться done. STEP 0 не даёт
фронтов. Reset — отдельная команда с двумя полными импульсами при dut_reset=1;
steps в ней игнорируется и reset-импульсы не входят в STEP.
Reset студенческой схемы синхронный; аварийный сброс контроллера не реализован.

| Событие | Задержка после принятия start, HALF_PERIOD=H |
|---|---|
| Первый положительный фронт при N>0 | H тактов sys_clk |
| Первый спад | 2H тактов |
| Последний спад | 2HN тактов |
| done и снятие reset | (2N+1)H тактов |
| STEP 0: done | H тактов, без фронтов |

Последний высокий и последующий низкий интервал имеют полную длину H.
Снимок разрешён только после done; вся шина уже стабильна H тактов.
`make test-clock` независимо считает posedge, проверяет длительность HIGH/LOW,
STEP 0/1/3/0..19/65535, команды reset и подряд, игнорирование busy и поздние
фронты за 1000 sys_clk и задержки таблицы. Проверки пройдены 2026-10-30
при HALF_PERIOD=2 и при реальном HALF_PERIOD=25. `make test-hdl` запускает
все обычные HDL-тесты без Quartus/платы, также добавлен в CI; удалённый CI
пока не запускался. Аппаратная проверка и vendor-модель — отдельные рубежи.
