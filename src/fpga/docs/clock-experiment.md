# Как выдать ровно N тактов

Тактовый сигнал задаёт моменты, когда схема делает следующий шаг.
Нам нужно уметь запустить несколько шагов, остановиться и спокойно прочитать
результат. Лишний импульс здесь означает лишний шаг студенческой схемы.

Сначала рассматривался готовый блок ALTCLKCTRL. Его модель не удалось
запустить в Icarus.

## Что проверено вместо него

`clock_burst.v` формирует медленный тактовый сигнал с помощью регистра.
При исходных 50 МГц он выдаёт 1 МГц: 25 исходных тактов сигнал низкий,
ещё 25 — высокий. Из таких полных импульсов собирается нужная пачка.
Этот вариант прошёл симуляцию и [проверку на плате](clock-board.md).
Полная работа через UART ещё не проверена.

- `start` запускает операцию, только когда `busy=0`.
- Пока `busy=1`, новые запросы игнорируются.
- STEP N выдаёт ровно N импульсов. STEP 0 не выдаёт ни одного.
- Reset — отдельная операция: два импульса при `dut_reset=1`.
  Они не входят в число рабочих шагов.
- `done` сообщает, что последний импульс закончился и выдержана пауза.
  После этого можно читать результат и отправлять следующую команду.

Число шагов передаётся в 16 битах. Это размер поля; допустимые пределы
для реального задания ещё нужно выбрать. Рабочая частота этого варианта —
1 МГц. Аварийный сброс самого контроллера пока не реализован.

## Когда заканчивается операция

H — длина половины импульса в тактах исходного clock. Для платы H=25.
Отсчёт начинается в момент принятия `start`.

| Событие | Через сколько исходных тактов |
|---|---|
| Первый положительный фронт, если N>0 | H |
| Первый спад | 2H |
| Последний спад | 2HN |
| done; для reset также снятие dut_reset | (2N+1)H |
| done для STEP 0 | H, без импульсов |

Низкая пауза после последнего импульса даёт выходам время установиться.
Тест `make test-clock` проверяет число фронтов, длительность HIGH/LOW,
задержки из таблицы, reset, запросы во время busy и отсутствие поздних
импульсов после остановки. Проверены N=0,1,3,0..19,65535 и H=2,25.
Этот тест входит в `make test-hdl`.
