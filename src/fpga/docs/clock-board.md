# Проверка генератора тактов на плате

Здесь проверяется, что генератор выдаёт нужное число импульсов на настоящей
C5G и счётчик не продолжает работать после остановки.

Команды из `src/fpga`:

```sh
make test-clock-board
(cd quartus && quartus_sh --flow compile clock_board)
quartus_pgm -c 1 -m jtag -o 'p;build/clock_board/clock_board.sof@1'
```

## Что должна показывать плата

Красные LED включаются по одному: LEDR0 → LEDR1 → … → LEDR9.
Каждый горит примерно секунду, последний — две. Затем примерно две секунды
все красные погашены, и цикл повторяется.

LEDG0 постоянно горит после первой успешной проверки. LEDG1 должен быть
выключен: он загорается при ошибке и остаётся включённым до перезагрузки схемы.

Внутри выполняется reset, затем STEP 0,1,1,2,4,8,16,32,64,128,256,0.
Независимый счётчик считает настоящие фронты полученного clock. Ожидаемые
значения: 0,0,1,2,4,8,16,32,64,128,256,512,512. Контроллер проверяет их
после каждой пачки и следит, чтобы в паузе счётчик не менялся.

На LED выводится сохранённый результат после остановки — снимок.
Промежуточные значения во время счёта скрыты, иначе при длинных пачках
появляются короткие вспышки. Вся шина считывается вместе после выдержки
25 исходных тактов, без отдельных синхронизаторов на каждом бите.

## Результаты проверки

Симуляция двух циклов, сборка, прошивка и визуальная сверка пройдены.
Порядок LED совпадает с ожидаемым, вспышек нет, LEDG0 включён, LEDG1 выключен.
Использовались Icarus 13.0 и Quartus Lite 23.1std.0 Build 991.

Quartus подтвердил, что оба clock идут по специальным глобальным сетям:
исходный — GCLK10, сгенерированный — GCLK9. В SDC задана связь частот
50 МГц → 1 МГц. Запасы setup/hold/ширины импульса положительные:
8.828 / 0.171 / 8.733 нс. Путей без временных ограничений нет.
Исключены из временного анализа только выходы на LED, у которых нет
внешнего считывающего clock; пути clock, reset и снимка проверяются.

Ошибок сборки нет. Девять предупреждений относятся к шести выключенным
LEDG2..7 и их общему предупреждению, функции LogicLock без подписки,
неуказанным силе тока и slew rate выходов LED.

Это проверка генератора 1 МГц с автономным сценарием. Управление им по UART
и полная служебная обёртка ещё предстоят.
