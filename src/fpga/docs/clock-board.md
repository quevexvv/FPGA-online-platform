# Прототип clock на C5G

Из `src/fpga`:

```sh
make test-clock-board
(cd quartus && quartus_sh --flow compile clock_board)
quartus_pgm -c 1 -m jtag -o 'p;build/clock_board/clock_board.sof@1'
```

Контроллер повторяет reset → STEP 0 → STEP 1,1,2,4,8,16,32,64,128,256
→ STEP 0 → reset. Независимый 10-битный счётчик обновляется только на
posedge фактического dut_clk и обнуляется синхронным dut_reset.
Ожидаемые снимки: 0,0,1,2,4,8,16,32,64,128,256,512,512.
Каждый снимок держится секунду; таким образом LEDR0..9 включаются по одному,
LEDR9 держится две секунды, затем две секунды красные выключены.

LEDG0 — проверка снимка прошла; LEDG1 — защёлкнутая ошибка. После первой
проверки LEDG0 должен гореть постоянно, LEDG1 оставаться выключенным.
Контроллер сравнивает всю шину после done и на каждом sys_clk в паузе;
лишний фронт/изменение счётчика/неостановленный clock защёлкивают ошибку.
Снимок уже стабилен 25 sys_clk; независимых синхронизаторов по битам нет.
LED подключены к отдельному регистру снимка после done, а не к живому
счётчику: промежуточные значения пачки на индикаторы не передаются.
