# UART-воздействия для ЛР3

`fpga-uart-stimulus` отправляет от 1 до 64 байт на 115200 бит/с с
восемью битами данных и одним стоп-битом. `even` задаёт штатный режим
`8E1`. `odd` задаёт `8O1`, поэтому для тех же данных в каждом кадре
инвертируется бит чётности. RTS/CTS и XON/XOFF отключены. Чётность
входящих ответов на хосте не проверяется, чтобы читать штатные ответы
`8E1` и после отправки неверных кадров. Флаги настройки описаны в
[документации termios](https://man7.org/linux/man-pages/man3/termios.3.html).

```bash
make -C src/fpga all
src/fpga/build/fpga-uart-stimulus /dev/ttyUSB0 even 41430d 3
```

Байты передаются парами шестнадцатеричных цифр. `0d` обозначает Enter
(CR). Последний аргумент задаёт число байтов ответа от 0 до 64. При
нуле утилита ждёт передачи очереди и завершает вызов без чтения.
При чтении утилита выводит ответ в hex после получения всех байтов.
Обычный обмен ограничен двумя секундами, ожидание передачи при вызове
без чтения ограничено ещё двумя. Ошибка настройки порта или обмена
возвращается ненулевым кодом.

## Проверка на C5G

Соберите доверенную фикстуру командой `make -C src/fpga build-lab3-uart-probe`.
Подключите USB-Blaster и проверьте имя кабеля и индекс устройства через
`jtagconfig`. Загрузите `src/fpga/build/lab3-uart-probe/lab3_uart_probe.sof`
в SRAM через Quartus Programmer. Выполняйте проверку под блокировкой
стенда и от той же учётной записи, что и аппаратные задания.

Затем переставьте кабель на FT232R, сохраняя питание C5G. Подставьте
путь устройства:

```bash
UART_PORT=/dev/ttyUSB0 flock -n "$HOME/.fpga-stand-lock" make -C src/fpga test-lab3-uart-hardware
```

Фикстура эхо-ответом подтверждает первые четыре байта строки и отвечает
`!` при превышении лимита. Правильный CR возвращает длину строки и
сбрасывает счётчик. Кадр с неверной чётностью даёт `%` и сохраняет
состояние строки. Это сервисная прошивка для проверки FT232R. Профиль
HEX и оценивание студенческого решения подключаются отдельно.

`make -C src/fpga test-lab3-uart-probe` независимо формирует кадры в
симуляции и проверяет чётность и стоп-бит ответов, строку, Enter,
границу четырёх символов и отказ при неверном стоп-бите на входе.

## Результат аппаратной проверки

Quartus Prime Lite 23.1 собрал фикстуру и обёртку MVP. У фикстуры
минимальный slack в TimeQuest составил 0,136 нс при TNS=0.
На C5G с FT232R последовательность `ABCDE<CR>` в `8E1` дала
`ABCD!4`. Затем в непустую строку отправили те же байты `A`, `C`
и CR в `8O1`. Фикстура вернула `%%%`; следующий правильный CR
вернул прежнюю длину `1`, затем повторный CR подтвердил очистку (`0`).

Отдельно подтверждены отправка без чтения, обмен 64 байтами подряд
и таймаут при запросе двух байтов ответа на кадр, дающий только один.

Для проверки бегущей строки с физическими индикаторами используйте
[сценарий варианта А](lab3-evaluation.md).
