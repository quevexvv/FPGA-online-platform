# С чего начать

FPGA-часть должна собирать проект, загружать его на плату, запускать проверку
и возвращать результат бэкенду. Пока готовы отдельные проверки оборудования
и форматы обмена. Полный запуск задания ещё не работает.

Уже проверены светодиоды платы и генератор, который выдаёт заданное число
тактов. Реализован C-транспорт UART с ограниченным ожиданием; проверен через PTY.
Команды протокола доступны в `build/fpga-uart`; обработка заданий ещё не реализована.
`fpga-dispatch` и `fpga-run` пока показывают справку и отклоняют рабочие команды.

Все команды ниже выполняются из каталога `src/fpga`:

```sh
make all       # Собрать C-проверки и проверить синтаксис скриптов
make test      # Проверить справку, JSON-примеры и формат UART-кадров
make test-hdl  # Проверить HDL в симуляторе, без платы
make lint      # Проверить shell-скрипты и C
```

Для этих проверок нужны Bash, Make, jq, ShellCheck и Icarus Verilog.
Quartus нужен для сборки прошивки, плата — для аппаратной проверки.
Примеры сборки и загрузки приведены в описаниях экспериментов.

| Документ | Что в нём искать |

| [Светодиоды](led-check.md) | Как проверить все 18 LED и какие выводы им соответствуют |
| [Симулятор](simulation.md) | Что проверяется без платы |
| [Генератор тактов](clock-experiment.md) | Как получить ровно N тактов и понять, что операция закончилась |

JSON-примеры иллюстрируют формат данных. Они не являются результатами
запуска платы. Конфигурационный пример пока не используется исполнителем.
