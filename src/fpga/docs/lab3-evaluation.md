# Аппаратная проверка ЛР3, вариант А

Пилот проверяет бегущую строку по варианту А из ЛР2. Плата получает
`123456` по UART `115200/8E1` и повторяет введённые цифры в консоли.
На четырёх HEX видны кадры `1234 → 2345 → 3456 → 2345 → 1234`.
Доверенный пример сдвигает окно каждые 250 мс. Кадр `9` в `8O1`
должен дать `%` и оставить прежний цикл анимации. Enter (`0d`)
гасит сегменты и посылает в консоль `ESC[2J` и `ESC[H`.

Критерий пилота — порядок кадров и UART-ответы в этом сценарии.
Телеметрия берётся с логических сигналов, подключённых к физическим
выходам, и не измеряет свечение или период сдвига. Доверенный пример
поддерживает цифры. Другие варианты ЛР2 и расширенный алфавит требуют
своих эталонов.

## Плата и запуск

HEX0/HEX1 используют пины 1,2 В. HEX2/HEX3 используют пины 3,3 В,
общие с GPIO22–GPIO35. Отключите оборудование от 40-контактного GPIO
и установите S1/S2 в ON на обесточенной плате. Сегменты активны нулём
на контактах, а в отчёте единица означает включённый сегмент.
Источник распиновки — [руководство Terasic, раздел 3.2 и таблица 3-5](https://www.unikeyic.com/media/datasheet/upload/2021/05/20/C5G.pdf).

1. Соберите `make -C src/fpga all build-lab3-evaluation`. Подключите
   USB-Blaster и загрузите только доверенный
   `src/fpga/build/lab3-evaluation/lab3_evaluation.sof` в SRAM через
   Quartus Programmer под блокировкой стенда. Перед каждым повтором
   загружайте проект заново, чтобы сбросить историю.
2. Сохраняя питание, переставьте кабель на FT232R и запустите:

   ```bash
   bash src/fpga/scripts/lab3-evaluate.sh uart /dev/ttyUSB0 > lab3-uart.json
   ```

3. Сохраняя питание, верните кабель в USB-Blaster и получите вердикт:

   ```bash
   bash src/fpga/scripts/lab3-evaluate.sh jtag lab3-uart.json 'USB-Blaster [3-1]' 1
   ```

Программа сохраняет по пять последовательных устойчивых кадров до и
после неверного байта и читает их через один согласованный JTAG-снимок.
Имя кабеля и индекс берутся из `jtagconfig`. Отсутствие ответа UART
или JTAG даёт `board_error`. Неверный байт ответа или кадр индикации
дают `mismatch`. При занятом стенде запуск UART завершается с кодом 75.

Симуляция `make -C src/fpga test-lab3-evaluation` проверяет эталон
и фикстуру, которая продолжает показывать строку после Enter.
Загрузка студенческого HDL и подключение к сайту выходят за рамки пилота.
