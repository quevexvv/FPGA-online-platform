# Онлайн-платформа для дистанционного выполнения лабораторных работ на ПЛИС

## Предпосылки:
1) Необходимость дистанционного доступа к стендам с ПЛИС.
2) Высокая стоимость и ограниченное количество оборудования.
3) Отсутствие единой среды для выполнения и проверки работ.

## Цели проекта:
* Цель проекта: Создать онлайн-платформу для удалённого выполнения лабораторных и курсовых работ по ПЛИС с доступом к реальному оборудованию. 
* Цель бизнеса: Повысить доступность обучения, эффективно использовать дорогостоящее оборудование, обеспечить гибкий формат.

## План работы:
1) Анализ учебных программ и стендов ПЛИС. 
2) Проектирование архитектуры. 
3) Разработка удалённого доступа к ПЛИС. 
4) Реализация личных кабинетов. 
5) Интеграция с САПР и средствами прошивки. 
6) Автоматическая проверка результатов. 
7) Тестирование и развертывание.

## План внедрения:
1) Пилотное внедрение на одной группе. 
2) Сбор обратной связи. 
3) Доработка. 
4) Масштабирование.

## Стек проекта:
* Стек: bash, С/С++, Python, JavaScript, Docker, WebSocket, PostgreSQL, Redis
* Фреймворки: FastAPI, Django, React, Celery

## Результат проекта
* Работающая онлайн-платформа с удалённым доступом к ПЛИС, личными кабинетами и автоматической проверкой.
